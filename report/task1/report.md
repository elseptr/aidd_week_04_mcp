# Отчёт о выполнении задания

## 1. Цель работы

Целью работы было сравнить использование AI-агентом специального skill `make_report` и выполнение той же задачи без него. Необходимо было оценить качество получаемых Excel-отчётов, стабильность результатов, расход токенов и время выполнения.

## 2. Результаты выполнения без skill

При выполнении задачи без skill агент самостоятельно анализировал исходные данные и создавал Excel-файл с помощью инструментов для работы с таблицами.

В результате экспериментов были обнаружены следующие проблемы:

- Результаты разных запусков отличались по структуре и оформлению.
- Возникали ошибки в расчётах и отображении данных.
- В одном из отчётов количество задач в категории «Срочные сейчас» составляло 9 вместо 8.
- Некоторые проценты и средние значения округлялись.
- Лист «Сводка» не всегда соответствовал требуемому формату.

При сравнении файлов `tasks1` и `tasks2` также было обнаружено расхождение во времени создания двух задач — №26 и №27. Значения `created_at` отличались от исходной базы на одну секунду. Остальные данные на листе «Задачи» совпадали с источником.

## 3. Результаты выполнения со skill

При использовании skill `make_report` агент находил соответствующую инструкцию и изучал её содержимое. В частности, он обращался к файлу `make_report.py`, после чего использовал готовую реализацию для формирования отчёта.

Результаты стали более стабильными:

- Структура Excel-файла соответствовала заданным требованиям.
- Расчёты выполнялись по единому алгоритму.
- Форматирование и оформление листов были одинаковыми при повторных запусках.
- Уменьшилось количество ручных операций со стороны агента.

Таким образом, skill позволил перенести повторяющиеся вычисления и оформление в готовый скрипт, вместо того чтобы каждый раз выполнять их вручную.

## 5. Последовательность вызовов инструментов

В процессе выполнения задачи использовались разные последовательности вызовов инструментов.

**Без skill:**

1. `ToolSearch` — поиск необходимых инструментов для работы с Excel.
2. Чтение исходных данных.
3. `create_workbook` — создание Excel-книги.
4. `write_range` — заполнение таблиц данными.
5. `format_range` — форматирование ячеек.
6. `set_sheet_layout` — настройка структуры и внешнего вида листов.
7. `describe_workbook` и `read_range` — проверка результата.
8. `record_artifact` — сохранение готового файла.

**Со skill:**

1. `Glob` — поиск файлов проекта и skill.
2. `ReadFile` — чтение инструкции и скрипта `make_report.py`.
3. `Shell` — запуск скрипта для формирования Excel-отчёта.
4. `describe_workbook` и `read_range` — проверка полученного файла.
5. `record_artifact` — сохранение готового результата.

При первом запуске скрипта возникла ошибка из-за неверно указанного пути к исходному JSON-файлу. После исправления пути повторный запуск завершился успешно.

В ходе этих экспериментов было замечено, что агент стабильно находил и использовал `make_report` даже при коротком описании задачи. В рамках проведённых проверок изменение названия и описания не привело к заметному изменению поведения агента.

## 7. Вывод

По результатам экспериментов можно сделать вывод, что использование skill значительно повышает эффективность выполнения повторяющихся задач.

В данном случае skill `make_report` позволил получить более стабильные Excel-отчёты, сократить количество ручных действий агента, уменьшить расход токенов примерно на 78% и время выполнения примерно на 70%.

Основное преимущество skill заключается в том, что он предоставляет агенту готовый алгоритм выполнения задачи. Благодаря этому агенту не приходится каждый раз самостоятельно разрабатывать структуру отчёта, повторять вычисления и настраивать форматирование.

При этом использование skill не гарантирует полного отсутствия ошибок: результат всё равно необходимо проверять на соответствие исходным данным и требованиям задания.
