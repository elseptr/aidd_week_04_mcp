## Назначение
Скрипт `make_report.py` читает задачи из `apps/todo/todo_db.json` (Flask-приложение `apps/todo`, поле `payload.tasks`, тот же JSON возвращает `GET /api/tasks`) и формирует один `.xlsx` с тремя листами: **«Задачи»**, **«Сводка»**, **«Определения»** — формат 1.1 по `tasks_export_requirements.txt`.

## Запуск

```bash
python practice/agent/.qwen/skills/make_report/make_report.py \
  --input apps/todo/todo_db.json \
  --output practice/agent/results/tasks_report_2026-11-04.xlsx \
  --today 2026-11-04
```

- `--input <json>` — путь к `todo_db.json` (обязательный).
- `--output <xlsx>` — куда сохранить отчёт; по умолчанию `practice/agent/results/tasks_report.xlsx`. Каталог результатов — **не исходные данные**.
- `--today YYYY-MM-DD` — дата расчёта (просрочка, дни до срока, «Создано сегодня»); по умолчанию текущая дата. Для детерминированных отчётов и тестов задавайте её явно.

Скрипт полностью детерминирован: значения в «Сводке» статические (без формул Excel), даты — настоящие значения, при ошибке частичный отчёт не остаётся.

## Проверка результата через openpyxl

```python
from openpyxl import load_workbook

wb = load_workbook("practice/agent/results/tasks_report_2026-11-04.xlsx")
print(wb.sheetnames)          # ['Задачи', 'Сводка', 'Определения']
ws = wb["Задачи"]
print(ws.max_row)             # 1 + число задач; A1:H{max} с автофильтром
print(ws["C2"].value)         # статус первой задачи
sw = wb["Сводка"]
print(sw["B2"].value)         # Всего задач
```

Проверяйте: `wb.sheetnames` — точный набор и порядок листов; даты в колонках E/F — экземпляры `date`/`datetime`, не строки; пустые поля — `None`; метрики строки 2–20 в «Сводке» совпадают с `todo_db.json`.

## Обработка ошибок
Отсутствие входного файла, пустой/повреждённый JSON, отсутствие обязательных полей, неверные типы, неизвестный приоритет, неправильный формат даты, неверный `--today`, невозможность записи — скрипт печатает понятное сообщение в stderr и завершается с кодом 1, не создавая (и не затирая) итоговый XLSX.

## Важно
Агент должен **запускать скрипт** (`make_report.py`) при запросах на экспорт задач и расчёт статистики, а не считать показатели и собирать Excel вручную. Существующие отчёты `tasks1.xlsx` / `tasks2.xlsx` в `practice/agent/` — референсы, не входные данные для скрипта.
